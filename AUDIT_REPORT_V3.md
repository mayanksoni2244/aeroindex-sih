## 3. Codebase Audit: Where Simulated and Live Data Currently Blend

Simulated and synthetic data currently penetrates the live calculation and presentation paths in **6 distinct architectural layers**:

### Layer 1: Data Ingestion (`apix/scrape/runner.py`)
- **Location:** `run_cycle()` (lines 402–406)
- **Mechanism:** When live scraping completes, `simulate_cycle()` is invoked with `skip_keys` to generate synthetic quotes for all remaining cells (and all other carriers: `6E`, `AI`, `SG`, etc.).
- **Blend Point:** `all_quotes = live_quotes + sim_quotes` is concatenated and deduplicated in memory, then written into the *same* `fare_quotes` database table under the *same* `cycle_date`.

### Layer 2: Cleaning & Imputation Pipeline (`apix/clean/pipeline.py`)
- **Location:** `impute_missing()` (lines 363–390)
- **Mechanism:** The imputation engine queries `routes_cfg.carriers` (expecting 6 carriers: IndiGo, Air India, Akasa, SpiceJet, Air India Express, Vistara). Because only Akasa Air is scraped live, it perceives 5 carriers as "missing" for every route.
- **Blend Point:** It pulls the previous cycle's quotes (which were synthetic quotes generated by Tier-B simulator in historical backfills) and carries them forward into the current cycle with `is_imputed = True`.

### Layer 3: Index Construction (`apix/index/construct.py`)
- **Location:** `_quotes_for()` (lines 310–317) & `compute_point()` (lines 320–375)
- **Mechanism:** `_quotes_for(session, cycle_date)` executes `SELECT * FROM fare_quotes WHERE cycle_date = :cycle_date` without filtering on `source_type`.
- **Blend Point:** It groups quotes by `(carrier, window)`. Consequently, the carrier `QP` (live) and carriers `6E`, `AI`, `SG` (simulated) sit in the same cell pool. Both feed directly into `elementary_relative()` (Jevons geometric mean) and Laspeyres upper aggregate. The resulting single `IndexValue` stored in `index_values` is a blended composite.

### Layer 4: API Endpoints (`apix/api/main.py`)
- **Location:**
  - `GET /v1/index` & `GET /v1/index.csv`: Returns `IndexValue` points that were computed from the blended live/simulated quotes.
  - `GET /v1/heatmap`: `_cell_medians()` selects all quotes for `cycle_date` regardless of source type and computes medians across live and synthetic quotes combined.
  - `GET /v1/routes/{route}/curve`: Computes advance-purchase price curves by grouping all quotes regardless of `source_type`.
  - `GET /v1/coverage`: Reports `routes_covered` as 6 because simulated data pads the remaining routes.

### Layer 5: Backtest Engine (`apix/index/backtest.py`)
- **Location:** `run_backtest()` (lines 140–210)
- **Mechanism:** Compares monthly aggregates of `IndexValue` against `DgcaMonthlyAvg`.
- **Blend Point:** The reference dataset contains 42 rows of `SYNTHETIC-PLACEHOLDER` data. The index it compares against is built from synthetic backfills. This results in circular validation of synthetic numbers against synthetic placeholders.

### Layer 6: Frontend Dashboard (`apix/web/src/`)
- **Location:** `App.jsx`, `IndexChart.jsx`, `BacktestPanel.jsx`
- **Blend Point:** The primary headline chart and metric cards directly render the blended index series. While dot colours indicate provenance, the line and overall index value combine real and synthetic data into a single curve.
